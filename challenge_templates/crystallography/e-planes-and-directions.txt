# QUESTION TYPES IN THIS TOPIC (levels · how it is answered)
# All of them use one rule: [uvw] lies in (hkl) when hu + kv + lw = 0.
#   dir-in-plane         easy, medium, hard · multiple choice
#       {plane} the plane · {check} hu + kv + lw worked out for the right answer
#   plane-contains-dir   easy, medium, hard · multiple choice
#       {direction} the direction · {check} as above
#   zone-axis            medium, hard · multiple choice or typed [uvw] (either sign counts)
#       {p1} {p2} the two planes · {cross} the cross product worked out
#   plane-from-two-dirs  medium, hard · multiple choice or typed (hkl) (either sign counts)
#       {d1} {d2} the two directions · {cross} the cross product worked out
#   coplanar-three       medium, hard · multiple choice
#       {plane} the plane that holds the right set · {checks} hu + kv + lw for each of the three

[topic]
name: Planes and directions (cubic)

[question]
type: dir-in-plane
text: Which of these directions lies in the plane {plane}?
explain: A direction [uvw] lies in the plane (hkl) when hu + kv + lw = 0. For {answer}: {check}.

[question]
type: plane-contains-dir
text: Which of these planes contains the direction {direction}?
explain: The plane (hkl) contains [uvw] when hu + kv + lw = 0. For {answer}: {check}.

[question]
type: zone-axis
text: Along which direction do the planes {p1} and {p2} intersect?
explain: The line where they meet lies in both planes, so it is perpendicular to both plane normals: take the cross product, {cross}. The opposite direction is also correct.

[question]
type: plane-from-two-dirs
text: Which plane contains both directions {d1} and {d2}?
explain: The plane's normal is perpendicular to both directions: take the cross product, {cross}. The indices with every sign flipped give the same set of planes.

[question]
type: coplanar-three
text: Which set of three directions all lie in one plane?
explain: The directions {answer} all lie in the plane {plane}: {checks}. In each other set one direction leaves the plane (the determinant of the three is not 0).
