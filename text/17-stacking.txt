# Close-packed stacking: ABAB… (HCP) and ABCABC… (FCC)

## Structures
stackStructureAB: Hexagonal close-packed (HCP)
stackStructureABC: Face-centred cubic (FCC), also called cubic close-packed
stackExamplesAB: Mg, Zn, Ti, Co, Cd
stackExamplesABC: Cu, Al, Ni, Ag, Au, Pt
stackHowAB: Every layer is a close-packed layer of touching spheres. Layer B sits in one set of hollows of layer A, and the third layer goes back right above A, so the pattern repeats every two layers.
stackHowABC: Every layer is a close-packed layer of touching spheres. Layer B sits in one set of hollows of layer A, and layer C in the other set, the hollows that B left free; only the fourth layer is right above A again.
