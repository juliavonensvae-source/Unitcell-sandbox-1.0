# Lattice picker (3D)
pickerSub: 14 lattices in 7 crystal systems{helpSystems}. Centring: P primitive · I body · F face · C base · R rhombohedral{helpCentring}
pickerPointsOne: {count} point / cell
pickerPointsMany: {count} points / cell

## Crystal systems: name and rule
systemCubic: Cubic
ruleCubic: a = b = c, α = β = γ = 90°
systemTetragonal: Tetragonal
ruleTetragonal: a = b ≠ c, α = β = γ = 90°
systemOrthorhombic: Orthorhombic
ruleOrthorhombic: a ≠ b ≠ c, α = β = γ = 90°
systemHexagonal: Hexagonal
ruleHexagonal: a = b ≠ c, α = β = 90°, γ = 120°
systemRhombohedral: Rhombohedral
ruleRhombohedral: a = b = c, α = β = γ ≠ 90°
systemMonoclinic: Monoclinic
ruleMonoclinic: a ≠ b ≠ c, α = γ = 90°, β ≠ 90°
systemTriclinic: Triclinic
ruleTriclinic: a ≠ b ≠ c, α ≠ β ≠ γ

## Crystal systems: description in the lattice picker
blurbCubic: Three equal edges, all at right angles.
blurbTetragonal: A cube stretched or squashed along c.
blurbOrthorhombic: Three different edges, all at right angles.
blurbHexagonal: Two equal edges at 120°, with c perpendicular to both.
blurbRhombohedral: A cube pushed along its body diagonal: equal edges, equal angles ≠ 90°.
blurbMonoclinic: Only one angle (β) differs from 90°.
blurbTriclinic: No constraints at all: the least symmetric lattice.

# Lattice picker (2D)

## 2D crystal systems: name, rule and description
system2DOblique: Oblique
rule2DOblique: a ≠ b, γ ≠ 90°
blurb2DOblique: No special lengths or angles: the least symmetric 2D lattice.
system2DRectangular: Rectangular
rule2DRectangular: a ≠ b, γ = 90°
blurb2DRectangular: Right angles, two different edge lengths. Comes primitive or centred.
system2DSquare: Square
rule2DSquare: a = b, γ = 90°
blurb2DSquare: Equal edges at right angles.
system2DHexagonal: Hexagonal
rule2DHexagonal: a = b, γ = 120°
blurb2DHexagonal: Equal edges at 120°: the pattern of a honeycomb or graphene.
