# Unit Cell Explorer

This is an interactive, playful learning tool for the 14 Bravais lattices. The site has a fully integrated crystallography mode, where you can add planes, directions, interstitial sites, and visualize the larger supercell and calculations in both 2D and 3D. The goal is to make a simple free tool for students that can help them in their studies of material structures. There is also an added defects mode, but functionalities are still being added.

Furthermore, I am also working on adding a Challenge mode, phase diagram mode and a material builder mode. These are still in the works and might still be far away. I greatly appreciate suggestions on how the website can be improved, and you can send them by opening an issue here on GitHub.

## Run it

You can use the GitHub link or download the program locally and follow the instructions below:
1. Install [Node.js](https://nodejs.org) (LTS) if you don't have it.
2. In this folder run `npm install` once.
3. Run `npm run dev`. The app opens at http://localhost:5173.

On Windows you can instead double-click **`start.cmd`**, which does steps 2–3 for you.

## Test it

`npm test` runs the verification suite (lattice points per cell, packing fractions,
d-spacings, Bragg angles, volumes, angles, Miller–Bravais conversions, interstitial
sites per cell and critical radius ratios…) (AI-generated TEST suggestion).
The same checks also run in the browser every time the app starts (⋯ → Self-check).
